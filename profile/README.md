# Survival Log mods by ivmakk

Open-source mods for *Survival Log*. Each mod is free on Nexus Mods, and its source code is here.

## Mods

| Mod | What it does | Version | Download |
|---|---|---|---|
| [Better Crafting](https://github.com/ivmakk-sl/sl-better-crafting) | Craft from any storage in your home: one click on a recipe fills the workbench with the missing materials from every cabinet and rack of your home. | 1.1.1 | [Nexus Mods](https://www.nexusmods.com/survivallog/mods/18) |
| [Better Trade](https://github.com/ivmakk-sl/sl-better-trade) | Improved Trading UI: see item prices, access to any Trading-tagged storage tabs, cleaner Delivery UI and reward previews. | 1.0.2 | [Nexus Mods](https://www.nexusmods.com/survivallog/mods/26) |

## Install

Each mod needs the [BepInEx Pack for Survival Log](https://www.nexusmods.com/survivallog/mods/12). Install it first, then extract the mod's zip into the game folder. With the Vortex mod manager, the [Vortex extension](https://www.nexusmods.com/site/mods/2471) installs the pack for you. The README of each mod gives the full steps.

## Bugs and ideas

Open an issue in the repo of the mod, or post on its mod page. For a bug, add your game version and the log file: `BepInEx\LogOutput.log` in the game folder.
